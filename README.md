# 抖音转录系统

当前账号喜欢列表与博主作品下载、批量转录、监听转录、逐字稿查看。

## 安装与桌面使用

支持 Windows 10/11 x64。将**这个文件夹单独复制或解压**到任何其它位置；不需要另外两个项目、原工作区、WSL、Docker、系统 Python 或 Node.js。

1. 双击 `安装.bat`，保持联网并等待显示 `Installed`。
2. 安装脚本会创建对应桌面快捷方式；双击即可打开操作界面。
3. 首次使用需在界面配置自己账号的 Cookie 或本人扫码登录。

也可双击 `启动.bat`。修改安装位置后，需要在新位置重新安装并运行 `创建桌面快捷方式.bat`。不要把其它机器的虚拟环境直接当成安装环境使用。

项目附带干净的 Python、安装器和 FFmpeg；首次安装联网下载本项目的依赖和浏览器。网络失败时脚本明确停止，可修复网络后重新运行。转录模型首次使用时下载到本项目的缓存，耗时取决于网络和设备。

## 目录与数据

- 源码与 `requirements.in` / `requirements.lock`：随项目分发，依赖版本锁定。
- `scripts/`：独立安装、启动和导出脚本；只引用本文件夹。
- `.venv/`：本项目自己的 Python 环境，不复制到另一台电脑使用。
- `.runtime/`：本项目自己的二进制、浏览器和模型缓存，不随源码分发。
- `.local/config/`：本机配置。
- `.local/credentials/`：Cookie、密钥及登录状态，不随源码分发。
- `.local/data/` / `.local/logs/`：本机数据库或运行数据/日志。

界面遇到平台登录失效、验证码或风控时，请本人处理；安装程序不能保证平台接口永久不变。

## 干净源码 ZIP

运行 `python scripts/export_release.py`（或用 `.venv\Scripts\python.exe`）导出 Git 已跟踪的源码。导出脚本拒绝运行组件、个人凭据和业务数据。导出目录由 `--output` 指定；本项目默认导出到 E 盘。

安装后的整个目录包含个人数据，不要整体上传。`.gitignore` 排除了本机运行目录。GitHub 仓库提供可浏览的源码与脚本，Releases 提供 Windows 独立安装包。公开发布的文件不含本机 Cookie、账号配置、数据库、音视频及模型缓存。

## 本项目

凭据保存在 `.local/credentials/cookie_like.txt`；`配置/` 保存当前账号身份等非密钥配置；媒体在 `video and audio/`，结果在 `输出/`。原操作台流程保留。

## 仅提取音频

展开“仅提取音频 · 保留原音质”，选择本地视频，点击“提取原音轨”，完成后下载音频。不需要登录，也不执行转录。保留视频第一条音轨的编码数据、采样率和声道，不重新压缩；根据原编码保存为 M4A、MP3、MKA、FLAC、WAV 等兼容格式。原视频不修改。

分发 ZIP 默认直接导出至 `E:\独立运行的工具项目压缩包`，不在项目目录生成副本；在其他电脑需要导出源码包时，可用 `python scripts/export_release.py --output 目标目录`。

## GitHub 下载

- 普通用户：打开本仓库 Releases，下载独立安装 ZIP，解压后双击 `安装.bat`。
- 开发者：克隆本仓库，或通过 Code → Download ZIP 获取源码；所需的 Python、uv 和 FFmpeg 运行组件保存在 `vendor/` 内，保留其压缩形式供安装脚本解包。
- 项目没有单独声明源码许可；第三方组件的许可与来源见 `vendor/NOTICE.md` 和组件包内文件。
- 当前版本验收包括独立安装、启动和界面检查；联网下载及转录结果受账号权限、平台接口和网络条件影响。
